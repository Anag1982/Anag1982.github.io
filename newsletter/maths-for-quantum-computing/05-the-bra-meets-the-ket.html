Amplitudes · Issue 5

The bra meets the ket

16 October 2026·6 min read·Avishek Nag

Last issue you learned to change one state into another: a gate is a matrix, and a circuit is a chain of them. What you still cannot do is compare two states. How much does one overlap another? Where do the measurement probabilities we keep quoting actually come from? Both questions have the same answer, a single number called the inner product, and it is where the bra ⟨ψ| finally joins the ket. By the end of this issue the normalisation rule we have been checking since issue 3 will stop being a rule and become a special case.

One number, first vector conjugated

The inner product of two states |φ⟩ and |ψ⟩ is written ⟨φ|ψ⟩, and the recipe is almost the familiar dot product: multiply matching components and add. Almost. Every component of the first vector is conjugated before the multiply, so for two-component states ⟨φ|ψ⟩ = φ₀*ψ₀ + φ₁*ψ₁. Work one by hand. Take |φ⟩ = (1, i) and |ψ⟩ = (1, 1). Conjugate the first to (1, −i), multiply and add: (1)(1) + (−i)(1) = 1 − i. The result is complex, and that is normal. Note also that swapping the arguments conjugates the answer: ⟨ψ|φ⟩ comes out as 1 + i. The order matters, which the plain dot product never cared about.

The conjugate is not decoration, and NumPy will happily let you omit it and be wrong. The honest call for complex vectors is np.vdot, which conjugates its first argument for you; np.dot never conjugates, agrees with vdot on real vectors, and silently returns the wrong bra-ket value the moment amplitudes go complex, which in quantum code is immediately.

import numpy as np

phi = np.array([1, 1j])    # |phi> = (1, i)
psi = np.array([1, 1])     # |psi> = (1, 1)

print(np.vdot(phi, psi))   # (1-1j) -> <phi|psi>, first argument conjugated
print(np.vdot(psi, phi))   # (1+1j) -> swap the order, get the conjugate
print(np.dot(phi, psi))    # (1+1j) -> WRONG for bra-ket: dot never conjugates

The norm is self-overlap

Why insist on the conjugate? Because of what happens when a state meets itself. The self inner product ⟨ψ|ψ⟩ becomes a sum of squared magnitudes, |ψ₀|² + |ψ₁|², real and never negative, so its square root is a genuine length, the norm ‖ψ‖. Skip the conjugate and a state like (i, 0) would report a negative squared length, which is nonsense. And now look at what the norm is for a qubit: the squared magnitudes of the amplitudes are the measurement probabilities, so ⟨ψ|ψ⟩ is their sum, and the condition |α|² + |β|² = 1 that issue 3 imposed on every state is exactly the statement ⟨ψ|ψ⟩ = 1. The normalisation rule we have been checking all along is the inner product of a state with itself, forced to equal certainty. To normalise a messy vector, divide it by its own norm:

psi = np.array([3, 4j])
print(np.linalg.norm(psi))            # 5.0 -> sqrt(<psi|psi>)

psi_hat = psi / np.linalg.norm(psi)
print(psi_hat)                        # [0.6+0.j  0. +0.8j]
print(np.linalg.norm(psi_hat))        # 1.0 -> now a valid state

The bra itself is nothing mysterious. A ket |ψ⟩ is a column vector; its bra ⟨ψ| is the matching row, formed by the same conjugate transpose that issue 4 called the dagger: ⟨ψ| = |ψ⟩†. That is why the notation ⟨φ|ψ⟩ works as written. A 1 × 2 row times a 2 × 1 column is, by the matrix rules of last issue, a 1 × 1 result, a single number. Dirac notation is a bookkeeping system for exactly this product, and nothing in it is new machinery.

Orthogonal means perfectly distinguishable

Two states are orthogonal when their inner product is zero: perpendicular as vectors, zero overlap as states. The computational basis is the cleanest example, ⟨0|1⟩ = (1)(0) + (0)(1) = 0, and each basis state has norm 1, so the pair {|0⟩, |1⟩} is called orthonormal. A tidy way to check orthonormality in one shot is the Gram matrix, the table of every pairwise inner product, which for an orthonormal basis is the identity:

ket0 = np.array([1, 0])
ket1 = np.array([0, 1])
plus = np.array([1, 1]) / np.sqrt(2)

print(np.vdot(ket0, ket1))            # 0 -> orthogonal
print(np.vdot(ket0, plus))            # 0.7071... -> <0|+> = 1/sqrt(2)
print(abs(np.vdot(ket0, plus))**2)    # 0.4999... -> probability one half

basis = [ket0, ket1]
gram = np.array([[np.vdot(a, b) for b in basis] for a in basis])
print(np.allclose(gram, np.eye(2)))   # True -> the basis is orthonormal

The middle two lines are the payoff of the whole issue. The state |+⟩ is not orthogonal to |0⟩; it overlaps it by an amplitude of 1/√2, the shadow it casts on the |0⟩ axis. Square that magnitude and you get ½, and here is the physical reading, stated now and earned in full when this series reaches measurement: |⟨φ|ψ⟩|² is the probability that a system prepared in |ψ⟩ is found as |φ⟩ when measured. The number ⟨φ|ψ⟩ is the amplitude for one state to be found as another, and its squared magnitude is the chance of it happening. Orthogonal states overlap by zero, so they are found as each other with probability zero, which means a single measurement can tell them apart perfectly. That is the entire reason measurement outcomes are built from orthonormal states.

One caution before the next step, because it is the most common slip in this corner of the subject. The probabilities only come out right when both vectors have norm 1, so normalise before reading any probability off an inner product. And keep the two NumPy calls straight: vdot conjugates its first argument, dot conjugates nothing, and code that passes its tests on real vectors can still be wrong on the first complex amplitude it meets. The error message never comes, because there is no error, only a wrong number.

You can now write states, transform them with gates, and compare any two of them with a single number. Next issue sorts the matrices themselves into the three families that run everything: Hermitian matrices, equal to their own dagger, whose always-real eigenvalues are the numbers a measurement can actually report; unitary matrices, revisited as the length-preservers; and projectors, the matrices that satisfy P² = P and that pick one outcome out of a state, connecting straight back to the |⟨φ|ψ⟩|² of this issue.
