Amplitudes · Issue 3

The ket is an ordinary column

18 September 2026·7 min read·Avishek Nag

A qubit is two complex numbers, and last issue left them lying loose. This issue builds the container: the vector, an ordered column of numbers, and the small set of rules for combining columns that all of quantum computing is written in. By the end, the notation |ψ⟩ will read as an ordinary column of complex numbers rather than a piece of decoration, which is exactly what it is.

From lists to columns

A Python list like [3, -1, 4] is an ordered collection of numbers. A vector is the same thing with one extra promise: the order carries meaning. The first entry is the first coordinate, the second is the second, and swapping them gives a different vector. That is the entire idea, and everything in this issue is bookkeeping on ordered tuples.

In this series a vector is a column, written stacked vertically. The column convention is not decoration. Next issue a matrix will multiply a vector from the left, and that operation only lines up if the vector is a column standing to the right of the matrix. Fix the convention now and the matrix issue costs you nothing.

import numpy as np

v = np.array([3, -1, 4], dtype=complex)
print(v)         # [ 3.-0.j -1.-0.j  4.-0.j]
print(v.shape)   # (3,)   -> three entries in a line
print(v[0])      # (3+0j) -> the top entry of the column

We passed dtype=complex even though the entries are real, and every entry now prints with a +0.j tail. That looks like clutter, and for quantum work it is the correct default: qubit amplitudes are complex numbers, and forcing the array to real would silently discard any imaginary part later. The number of entries is the vector’s dimension. Almost every vector in the rest of this series has exactly two, and the reason is coming.

Add, scale, combine

Two operations define a vector space, and both act entry by entry. To add two vectors of the same length, add their matching entries. To scale a vector by a number, multiply every entry by it, and the scalar is allowed to be complex, including 1j. Combine the two and you get a linear combination: scale several vectors, add the results. It is the single most important construction in the subject, because a qubit state is a linear combination of two fixed vectors, and every gate produces another one.

u = np.array([1, 0], dtype=complex)
w = np.array([0, 1], dtype=complex)

print(2 * u + 3 * w)   # [2.+0.j 3.+0.j]  -> walk 2 along u, then 3 along w

For real 2-vectors the picture is arrows on a plane, and addition is walking one arrow after the other. Complex entries break the picture, since a complex 2-vector needs four real numbers to plot, but the algebra does not change: add entrywise, scale every entry. Hold the arrow picture as a memory aid for the real case and trust the arithmetic for the complex one.

Basis, span, and why a qubit is two-dimensional

In the code above, every 2-vector we could want is reachable as a combination of u = [1, 0] and w = [0, 1]. That is not luck. It is the defining property of a basis: a set of vectors that spans the space, meaning every vector is some combination of them, with none of them redundant. The pair [1, 0] and [2, 0] fails the test, because both point along the same line and their combinations never leave it.

The two vectors [1, 0] and [0, 1] are the standard basis, and it earns the name standard because coordinates and entries coincide: the vector [7, -4] has coordinate 7 on the first basis vector and −4 on the second, and you read them straight off. The dimension of a space is the number of vectors in any basis for it. The space of complex 2-vectors, written ℂ², has dimension 2, and a single qubit lives in exactly that space. Two qubits live in ℂ⁴, and n qubits in a space of dimension 2ⁿ, which is where the size of quantum computing comes from, but this issue stays at one qubit.

Why complex entries rather than real ones? Because a qubit’s two amplitudes must be able to interfere, and interference needs a relative phase, which is an angle. A complex number r eiθ carries a size and an angle in one object, and the angle is exactly the phase from last issue. Strip out the imaginary part and the gates two issues from now stop behaving. This is a physical fact about the theory, confirmed by experiment, not a modelling choice anyone could reverse.

The unit-length rule

A qubit state is written |ψ⟩ = α|0⟩ + β|1⟩, with complex amplitudes α and β. As a vector it is simply the column [α, β]. The amplitudes are not free: they must satisfy |α|² + |β|² = 1. The reason is measurement. Measuring the qubit gives 0 with probability |α|² and 1 with probability |β|², and the probabilities of the only two outcomes must sum to one. So a valid state is a unit vector, length exactly 1, and a vector like [1, 1] is a direction rather than a state until you rescale it:

psi = np.array([1, 1], dtype=complex)
norm = np.linalg.norm(psi)          # sqrt(|1|^2 + |1|^2) = 1.4142...
psi_unit = psi / norm
print(psi_unit)                     # [0.707+0.j 0.707+0.j]

prob = np.abs(psi_unit) ** 2
print(prob)                         # [0.5 0.5]
print(np.isclose(prob.sum(), 1.0))  # True

Note the check on the last line. The probabilities sum to 0.9999999999999998, not exactly 1, and the gap is floating-point rounding rather than physics. Never test a normalised state with ==; it will fail on rounding alone. np.isclose is the honest comparison, and building the habit here saves an evening of debugging later.

Reading the ket

Dirac’s notation |ψ⟩ is called a ket, and it is nothing more than a named column. The bars and bracket are a label saying this object is a quantum state vector, and the letter inside is its name. The two basis kets are the columns we have used all along: |0⟩ is [1, 0] and |1⟩ is [0, 1]. The state built by combining them equally, then normalising, has a name of its own:

ket0 = np.array([1, 0], dtype=complex)
ket1 = np.array([0, 1], dtype=complex)

ket_plus = (ket0 + ket1) / np.sqrt(2)
print(ket_plus)                  # [0.707+0.j 0.707+0.j]
print(np.abs(ket_plus) ** 2)     # [0.5 0.5]

That is |+⟩, the equal superposition: measuring it gives 0 half the time and 1 half the time. Its cousin |−⟩ = (|0⟩ − |1⟩)/√2 has the same two probabilities, because squaring a magnitude erases the sign, yet it is a different state, and the difference is a relative phase of the kind last issue promised would matter. The gates that separate the two are one issue away.

A qubit, then, is a unit column in ℂ², and you can now write down any single-qubit state and check that it is legal. What you cannot yet do is change one state into another. A quantum gate takes a state in and returns a state out, and the object that does it is a matrix: multiply the column by a 2 × 2 grid of complex numbers and you get the new column. Next issue builds matrices as the verbs acting on this issue’s nouns, shows why the NOT gate is a small swap matrix, and proves the one property every legal gate must have.
