Attention, Derived · Issue 6

Where 14336 comes from

30 October 2026·7 min read·Avishek Nag

Two thirds of a dense transformer’s non-embedding parameters are not in attention. They sit in a two-layer network that every explainer disposes of in one sentence on the way back to the interesting part. Open any 2026 model config and the line is there: "hidden_size": 4096, "intermediate_size": 14336. The ratio is 3.5. It is not the 4 of the original paper, and it is not the two thirds of 4 that the gated convention is supposed to give. This issue answers three questions about that line. What does the block compute, stated as a theorem about the layer rather than a metaphor for it? What did gating actually change, given that the field files it under activation functions and it is not one? And where does 14336 come from? The third answer is four lines of integer arithmetic, and it is worth 19.2 percent of the model.

A memory with 14336 entries

Write the block out. With x the residual stream at one token, the layer is FFN(x) = φ(xWup)Wdown, two matrix multiplies with an elementwise nonlinearity φ between them. That is where most descriptions stop. Expand it once and the black box opens. The up-projection has 14336 columns; call them keys, kⱼ. The down-projection has 14336 rows; call them values, vⱼ. Then the layer is a sum over 14336 units, and every unit does the same two things: it measures the stream against one learned direction, ⟨x, kⱼ⟩, and it writes one learned direction back, vⱼ, in proportion to the thresholded measurement. The block reads the stream against a fixed dictionary and writes back a weighted sum of what it found. That is a key-value memory, and the restatement is an identity, not an analogy: the two forms are the same function, term for term.

import numpy as np
from math import erf
rng = np.random.default_rng(0)

d, dff = 6, 8                       # toy sizes; the real ones are 4096 and 14336
x = rng.normal(size=(1, d))
W_up = rng.normal(size=(d, dff))
W_down = rng.normal(size=(dff, d))
gelu = np.vectorize(lambda z: z * 0.5 * (1 + erf(z / np.sqrt(2))))

block = gelu(x @ W_up) @ W_down                  # the layer as two matmuls
units = sum(gelu(x @ W_up[:, j:j+1]).item() * W_down[j]
            for j in range(dff))                 # the layer as dff read-write units
print(np.allclose(block, units))                 # True -> same function, term for term

The contrast with attention is the useful part. Attention’s coefficients are a normalised distribution over positions: one full unit of mass, placed somewhere, every time. The FFN’s coefficients are unnormalised scores against a dictionary that never changes with the sequence, so the block can return nothing at all when every score falls below threshold. One honest caution before the metaphor runs away: there are 14336 keys in 4096 dimensions, so they cannot all be orthogonal, and a stream state that matches one key generally matches several. One unit is not one concept.

Gating is not an activation function

The nonlinearity between the matmuls, GeLU, is itself an expectation in disguise: GeLU(z) = zΦ(z), the mean of a gate that keeps z with probability set by z’s own magnitude. It is also, less famously, not monotone. Its derivative has a root at z = −0.7518, and to the left of that point making a pre-activation larger makes the unit’s output smaller, with a minimum value of −0.1700. The dip is small, and it is not an artefact; it is the price of a gate whose probability is a smooth function of the input, and issue 7 will need it, because it is where a backward pass through the block can flip sign.

Modern models do not use plain GeLU. The config says "hidden_act": "silu" because the block is gated: two up-projections instead of one, the layer computing [φ(xWgate) ⊙ (xWup)]Wdown, an elementwise product of a gate branch and a linear branch. The field lists SwiGLU in the activation-function column of benchmark tables, and that is a category error rendered as a table header. Expand one gated unit to lowest order and its leading term is ½⟨x, wⱼ⟩⟨x, vⱼ⟩: a product of two different learned directions, quadratic in x. No pointwise function of a single projection can produce a term like that. An ungated unit’s second-order term is a square, one direction times itself, non-negative, a valley; a gated unit’s is an arbitrary rank-1 interaction, a saddle with both signs available. Synthesising one gated unit’s quadratic from ungated units takes exactly two of them, and the factor of two is provably unimprovable. Gating changes what the layer can compute, not how sharply it thresholds. The honest footnote: at matched parameters the measured SwiGLU win is single-digit percentage points of perplexity, and the paper the comparison comes from attributes the improvement, in an unusually honest sentence, to divine benevolence.

Four decisions in one number

Now the number. Gating costs a third matrix, so comparing gated against ungated fairly means holding parameters fixed: an ungated block holds 2 · d · dff parameters, a gated one 3 · d · d′, and equating them gives d′ = ⅔dff. That is the entire two-thirds convention, a comparison protocol from 2020, never a claim about the best width. Watch it get applied, then overridden, in the reference code of the most-cited open model family. Start at the classical width 4d = 16384. Take two thirds: 10922. Multiply by a capacity factor of 1.3, because somebody wanted the parameters back: 14198. Round up to a multiple of 1024, because 14336/8 = 1792 divides evenly across eight-way tensor parallelism and 10922/8 does not: 14336.

from math import ceil

def ffn_width(d, multiplier=1.3, multiple_of=1024):
    h = 4 * d
    h = int(2 * h / 3)
    h = int(multiplier * h)
    return multiple_of * ceil(h / multiple_of)

print(ffn_width(4096))   # 14336 -> the config line decoded
print(ffn_width(8192))   # 28672 -> the published width of the 70B sibling

The second line is the check that this is the recipe rather than a reverse-engineering of one number: the same four steps at d = 8192 give exactly the published width of the family’s 70-billion-parameter member. And the 1.3 is not small change. At width 14336 the FFN holds 176 million parameters per layer, 5.64 billion over 32 layers, which is 80.8 percent of the model’s non-embedding total; at the exact two-thirds width the same model would be 19.2 percent smaller. The convention everyone quotes is, in the flagship model everyone cites, not used.

Note what the block’s share of the parameters buys in intuition. The attention mechanism occupies most of the picture in every architecture diagram ever drawn and about a fifth of the parameters; the block the diagrams shrink to a rectangle holds four fifths. That share is why mixture-of-experts sparsifies the FFN and leaves attention dense, and why quantisation and pruning effort goes to the FFN first. One more cost hides in the gating: at equal parameter count the gated block materialises two intermediate tensors where the ungated kept one, a third more peak activation memory, which is why a gated model sometimes will not fit a micro-batch that an ungated model of the same size did. No paper states this. The arithmetic does.

The forward pass of the transformer is now complete on this series’ terms: embeddings, attention, normalisation, position, and the feed-forward memory. What has not been touched is the direction the whole machine actually trains in. Next issue runs the derivatives backwards: the chain rule organised into backpropagation, the Jacobians of each block in the order the gradient meets them, the two matrix products every layer must save its inputs for, and the place this issue already flagged, the interval where GeLU’s negative slope can flip the sign of a gradient on its way down.
